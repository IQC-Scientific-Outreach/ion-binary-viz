Ion Data Converter

This turns your 8 ion_peak_1.csv–ion_peak_8.csv files into a single ion_data.js file that the visualizer can load with a plain <script> tag instead of fetch() — which is what lets it work when you open index.html directly from disk (on Windows, a Raspberry Pi, wherever), with no local web server needed. Everything happens in your browser; nothing is uploaded anywhere.

  1. Select all 8 CSV files below (ctrl/shift-click to multi-select in the file picker, or drag them onto the box).
  2. Click "Download ion_data.js" once all 8 show green.
  3. Move the downloaded file into the same folder as index.html (next to script.js), replacing any old copy.
  4. Open (or reload) index.html — it will now work fully offline. You only need to redo this if your CSV data changes.
